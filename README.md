# 🚀 EduVista

> AI-powered visual learning platform that helps students understand concepts through interactive visual explanations.

---

## 📖 Vision

Every student deserves an AI teacher that explains concepts visually instead of making them memorize.

---

## 🎯 Mission

Build an AI-powered education platform that makes learning simple, visual, and personalized.

---

## ✨ MVP Features

- 🔐 Login & Signup
- 🏠 Home Dashboard
- 🤖 AI Chat Teacher
- 📊 Visual Diagram Generator
- 📝 AI Quiz Generator
- 📈 Progress Tracking
- 📚 Learning History
- 👤 User Profile
- 🎙️ Voice Learning
- ⚙️ Settings
